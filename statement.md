# EduRisk AI

## Problem Statement

It can be difficult for educational institutes to identify students who may need academic support by looking at several learning and performance indicators manually. EduRisk AI is a machine learning prototype that uses these indicators to classify a student's academic risk as Low, Medium, or High.

The project is intended to demonstrate how machine learning can be used to analyse student-related data and provide an initial risk classification.

## Scope

The project covers the complete process from loading and validating the student dataset to preprocessing the data, training classification models, comparing their performance, and predicting the academic risk of an individual student.

It also includes probability-based prediction output, rule-based risk indicators, and suggested academic interventions. The system can be used through a command-line interface, with an optional Streamlit dashboard for visual demonstration.

The dataset used in the project is synthetic and is intended only for academic demonstration.

## Target Users

The intended users of EduRisk AI are:

- Students
- Faculty mentors
- Academic support teams
- AI/ML learners

## High-Level Features

1. Student data loading and validation
2. Data preprocessing and feature preparation
3. Training and comparison of multiple machine learning models
4. Prediction of Low, Medium, or High academic risk
5. Display of prediction probabilities
6. Rule-based identification of risk indicators
7. Suggested academic interventions
8. Command-line interface for prediction
9. Optional Streamlit dashboard for visual demonstration

## Input

The system uses the following student-related indicators:

- Attendance percentage
- Study hours per day
- Assignment score percentage
- Internal marks percentage
- Previous GPA
- Previous backlogs
- Sleep hours per day
- Class participation percentage

## Output

The system provides:

- Predicted academic risk level
- Probability distribution for the risk classes
- Rule-based risk indicators
- Suggested academic interventions
