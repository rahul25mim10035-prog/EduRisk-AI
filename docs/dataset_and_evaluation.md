# Dataset, Model Selection and Evaluation

## Dataset Description

`data/student_performance.csv` is a synthetic demonstration dataset containing student-related academic and learning indicators.

Input features:

- `attendance_pct`
- `study_hours_per_day`
- `assignment_score_pct`
- `internal_marks_pct`
- `previous_gpa`
- `previous_backlogs`
- `sleep_hours`
- `class_participation_pct`

Target:

- `risk_level` with the classes `Low`, `Medium`, and `High`.

The dataset is intended for demonstrating the software and ML workflow. It does not represent a real institutional student population.

## Model Selection

Three classification algorithms are compared:

1. Logistic Regression
2. Random Forest
3. Gradient Boosting

All models use the same preprocessing pipeline. This keeps the comparison consistent. The model with the highest weighted F1 Score on the held-out test set is selected for the final prediction pipeline.

## Evaluation Methodology

- Train/test split: 80% training and 20% testing
- Stratification: enabled to preserve class distribution
- Random state: 42 for reproducibility
- Metrics: Accuracy, weighted Precision, weighted Recall, weighted F1 Score

The training script stores the comparison in `models/model_results.csv` and saves the selected fitted pipeline as `models/trained_model.pkl`.

## Interpretation Note

The project has two separate ideas that should not be confused:

- **ML prediction:** generated by the selected trained classifier.
- **Key indicators:** generated by simple predefined rules for readable feedback.

The rule-based indicators are not proof that a particular factor caused the prediction.
